# Changelog

This file records user-visible changes in released versions.

## 0.1.3 — 2026-11-23

- Added a navigable Markdown example with a task list, table, links, Mermaid diagram, and three anchored comments.
- Replaced the README gallery with one real Windows screenshot and made CLI and MCP visible in both READMEs.
- Included the example, screenshot, and README icon in release archives.

## 0.1.2 — 2026-11-22

- Unified the app icon as a large MD mark across the README and desktop bundles.
- Added a Windows per-user installer that registers pane-md for Markdown files and makes it available in Default apps and Open with.
- Added a GUI file launcher, so Explorer and external editor shortcuts open pane-md without an extra terminal window.

## 0.1.1 — 2026-11-22

- Added Windows Explorer version details and a Linux application menu launcher.
- Expanded repository and bundle descriptions for the public release.

## 0.1.0 — 2026-11-22

- First public release, with portable archives for Windows x64 and Linux x64 and a universal macOS app.
- WYSIWYG and Markdown source editing, tabs, a file explorer, an outline, search, and keyboard shortcuts.
- In-file review comments, including anchored cards and resolved state.
- Markdown images, links, tables, tasks, emoji, and Mermaid diagrams.
- CLI linting and a local STDIO MCP server.
- English and Russian UI, light and dark themes, and appearance settings.
